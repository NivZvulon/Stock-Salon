STOCK SALON — V1 FRANÇAIS / HÉBREU

Fonctions :
- scan code-barres via caméra si le navigateur prend en charge BarcodeDetector ;
- saisie manuelle du code-barres en secours ;
- création des produits ;
- entrées / sorties de stock ;
- mode inventaire ;
- seuil de stock faible ;
- historique des mouvements ;
- export CSV compatible Excel ;
- interface français / hébreu avec sens RTL en hébreu ;
- données enregistrées localement sur le téléphone.

INSTALLATION PWA SUR IPHONE
1. Héberger ce dossier sur un serveur HTTPS (GitHub Pages, Netlify, serveur du salon, etc.).
2. Ouvrir l'adresse dans Safari.
3. Partager > Sur l'écran d'accueil.
4. Autoriser la caméra au premier scan.

IMPORTANT
- Ouvrir index.html directement depuis l'application Fichiers permet de voir/tester l'interface, mais iOS peut bloquer la caméra et l'installation PWA depuis un fichier local.
- Les données de cette V1 sont locales à l'appareil. Utiliser régulièrement l'export CSV comme sauvegarde.
